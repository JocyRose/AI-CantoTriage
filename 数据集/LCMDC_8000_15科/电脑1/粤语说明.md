# 电脑1粤语改写

这是电脑1七个科室的单轮文本。中文 `train.jsonl`、`test.jsonl` 没有改，粤语在各科室的 `粤语/` 目录。

没有从约 44 万条里重抽。只改写已经抽好的记录；辅助检查科不够的部分，用清洗后的 webMedQA 原问补入。

## 格式

训练、验证、测试都是一行一条 JSON：

```json
{"input": "聽神經瘤做手術後會有咩情況？", "output": {"建議科室": ["外科"], "簡單原因": "聽神經瘤做手術後會有咩情況，適合由外科評估。"}}
```

`建議科室` 用繁体科室名。`簡單原因` 只截取主诉，再写“適合由某科評估”。不编造诊断、治疗或原文没有的事实。同名 `.meta.jsonl` 只保留来源和划分，不参与训练。

## 划分

沿用制备 281/48/99 时的规则，不按 281:48:99 重新凑条数。

- LCMDC 官方测试集仍全部放在 `test.jsonl`。
- 官方训练集不进入测试。正文先做 NFKC、去掉空白，再取 SHA-256。`case_id` 前 8 位十六进制模 10 等于 0 的进 `validation.jsonl`，其余留在 `train.jsonl`。
- 划分用原始中文正文计算，不按改写后的粤语重算。
- webMedQA 保持自己的划分：`train` 进训练，`valid` 只进验证，`test` 进测试。验证和测试问句不并进训练，也不并进 LCMDC 的测试集。

## 改写

规则替换加 OpenCC `s2hk`。不是人工翻译，也没有按 CCPC 逐句对齐。病名不改。“还是不/没”先改成“仍然”，避免变成选择问句。展示正文用患者能看的句子；标题只是正文截断时不重复拼接。

这些句子不能当成人工粤语，也不能当成临床安全标注。

复现：

```text
python scripts/rewrite_pc1_yue.py --write
```
