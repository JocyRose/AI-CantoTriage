# 粤语 AI 语音导诊技术方案

同步日期：2026-11-25。对应 [Word 方案](粤语AI语音导诊方案.docx) 和 [PPT 方案](粤语AI语音导诊方案.pptx)。以下为待实施的任务适配设计，不表示已经完成训练或评估，也不表述为官方全参数训练的完整复现。

## 1. 输入、输出与模型内部

输入为病人粤语口语主诉语音＋粤语文字指令；指令要求用粤语口语回答，并将诊室推荐限制在既定 14 个诊室。输出为相互对应的粤语口语文字与粤语口语语音。

语音编码器与输入投影将主诉转换为特征，与文字指令共同输入 Thinker。Thinker 学习主诉理解、诊室选择和口语回答，回答相关隐藏表示为 Talker 提供条件。Talker 自回归预测语音 token，固定波形解码模块还原语音。

Thinker 和 Talker 分别加入 LoRA，**两个阶段均更新两组 LoRA**。冻结原模型基础权重、语音编码器及输入投影、语音 tokenizer 与波形解码模块。LoRA 注入层、秩、学习率及损失权重在实施时核对，并由验证集选择。

## 2. 两阶段训练

### 第一阶段：联合监督微调

使用既有训练输入、标准粤语口语回答文字及其对应配音；配音须经审核，并由固定 tokenizer 转为目标语音 token。采用教师强制训练：

`L1 = λ_text × CE_text + λ_speech × CE_speech`

仅在回答文字与目标语音 token 上计算对应交叉熵，屏蔽提示、输入和填充位置。文字损失学习推荐内容与口语表达，语音损失学习发音及语音序列；联合更新 Thinker、Talker LoRA。语音损失可沿可微隐藏表示路径回传至 Thinker。按既有验证划分选择检查点，得到模型 B。

### 第二阶段：生成回答与语音自对齐

1. 固定 B，仅在原训练集输入上生成粤语口语回答，核对诊室、病例事实与口语表达。
2. 为通过审核的文字重新生成对应粤语配音并听审，固定这批文字—语音监督；修改文字时同步重制或核对音频。
3. 每个训练步骤用当前 Thinker 以教师强制重新计算回答隐藏表示；Talker 结合这些表示与目标语音历史预测新语音 token。
4. 以 `L2 = CE_speech` 经 Talker 和隐藏表示路径同时更新两组 LoRA，得到模型 C。

外部 TTS、离线文字生成及离散采样不参与反向传播。不得缓存并分离可训练 Thinker 的隐藏表示。若增加文字损失、旧数据回放或冻结 Thinker，须作为额外变体记录。

第二阶段复用原训练病例，新增的是派生回答与配音版本，不增加独立病例数；不使用验证或测试输入制作训练监督。测试时由模型本身输出文字与语音。

## 3. 四组模型比较

| 模型 | 定义 | 比较用途 |
| --- | --- | --- |
| A | 原始 DialectS2S，未进行本项目任务适配 | 原模型基线 |
| B | 第一阶段联合监督微调 | B 对 A：任务适配收益 |
| C | B＋第二阶段自对齐 | C 对 B：第二阶段收益 |
| D | 同一个 B＋等量普通第一阶段 SFT | C 对 D：区分自对齐与额外训练的收益 |

C、D 匹配新增优化步数、有效批大小与学习率计划，尽量匹配训练输入，并记录实际样本数、语音时长及目标 token 数；审核造成输入差异时单独报告。四组使用同一既有验证和测试划分，不在测试集调参。

分别评价诊室正确性与范围、文字事实与口语表达、语音发音与自然度及可懂度、文字语音一致性与联合正确性。一致性不等于推荐正确；合成语音和未来真人语音的结果分开报告。

## 4. 补充实验：第一阶段数据量分析（暂不实施）

待合格训练样本充足后，在既有训练划分内构建 1400、2800、5600、6400 条嵌套子集；各组从同一个原始检查点独立完成第一阶段训练。保持验证与测试划分固定，记录训练步数和成本。这不是递增接续训练，也不是按 14 个诊室依次训练。

## 5. 数据与当前状态

目标规模约 8000 个病例样本；既有数据内容、结构和划分保持不变。本次发布不新增或改写病例。每例包含粤语口语主诉语音、粤语文字指令、粤语口语回答文字与回答语音；第二阶段监督作为训练集派生版本管理。

目前已有 14 科共 84 条配对样本、168 段云端合成音频，沿用 42 条训练、14 条验证、28 条测试的划分。此前发布的双模块 LoRA 及 28 条测试报告属于历史实验，不是本方案中 B/C/D 的新结果。新方案的标注听审、两阶段训练和四组评估尚待完成。
