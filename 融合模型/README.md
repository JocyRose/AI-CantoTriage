# 未训练融合初始化

本目录是 Qwen3-ASR 音频塔与 Qwen3-1.7B 解码器的连续特征融合初始化，尚未训练。

音频特征保持连续，经一个无偏置线性对齐层进入原来的文字解码器。对齐层初始化为单位矩阵。它还不能跟随粤语语音指令，必须再用成对的语音指令数据做监督微调。

这里没有粤语指令能力、导诊能力或临床结论。

- `tools/cascade.py`：离散级联。先转写，再把文字交给原始文本模型。
- `tools/run_fusion.py`：连续融合。直接使用本目录的融合权重。

加载分词器时不要把 `fix_mistral_regex` 设为 `True`，否则会改掉原有预分词。
四个 safetensors 分片的 SHA-256 在 `checksums.json`。本目录不包含 `_runtime`，请按 `requirements.txt` 安装依赖。离散级联还需要上一级的原始 `粤语ASR` 和 `基础模型/Qwen3-1.7B`，这两个模型没有放进仓库。
